# Smart Health Assessment System

## Project Overview
The Smart Health Assessment System is a web application developed to collect user-provided health measurements and display assessment results and health recommendations.

This project is intended for educational purposes and does not replace professional medical advice or diagnosis.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Jinja2

## Main Features
- Health assessment form
- Display of assessment results
- Health measurement summaries
- Health recommendations
- Reset button to clear the form
- Responsive layout for desktop and mobile screens

## How to Run the Project

1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Install the required dependency:

   `python -m pip install -r requirements.txt`

4. Start the application:

   `python app.py`

5. Open your browser and visit:

   `http://127.0.0.1:5000/`
